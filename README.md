# Java Module III – Practical Assignment

**Subject:** CSIT751 – Core Java

**Module:** III – Exception Handling, Interface and Threads

## About the Project
This repository contains 10 Java programming exercises completed as part of the Module III Practical Home Assignment.

## Programs Included
1. ATM Withdrawal System – Exception Handling
2. Student Age Validation – User Defined Exception
3. Array Division – Multiple Catch
4. Student Marks Entry – Input Validation
5. University Login – Null Pointer Handling
6. Online Shopping – Minimum Purchase Exception
7. Railway Ticket Booking – Thread Synchronization
8. University Printing System – Multiple Threads
9. IoT Sensor Monitoring System
10. Bank Transaction System – Thread Priorities
